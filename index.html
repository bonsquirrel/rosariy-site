Розарий

Личное приложение для учёта роз и других растений в саду.

План участка с рядами и лунками, карточки растений с фото, категории, поиск по названию и цвету, печать и резервные копии. Приложение сделано для одного человека — хозяйки розария — и не продаётся.

Данные хранятся на телефоне. По желанию пользователя копии сохраняются в его собственный Google Диск (приложение видит только созданные им файлы).

Политика конфиденциальности

Rosariy

A personal app for keeping track of roses and other plants in a garden.

Garden plan with rows and planting holes, plant cards with photos, categories, search by name and colour, printing and backups. The app is made for a single person — the owner of the rose garden — and is not sold.

Data is stored on the phone. If the user chooses, backups are saved to the user's own Google Drive (the app can only see files it created).
